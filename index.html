COLOR

ALCHEMY

You start with three squares of light — red, green and blue. Put two together and see what they make. Three hundred elements later you will have mixed a rainbow, forged a unicorn, boiled ratatouille out of a rat and a chef, and worked out how to turn opposite colours into a lump of matter.

The whole game is one HTML file that fits in 13 kilobytes — the board, the recipe tree, the artwork, the music and the sound effects, with nothing loaded from anywhere.

The same game with nothing to fit into: a written quote for every element, fireworks over each completed quest, and its own bundled emoji font instead of whatever your device happens to own.

HOW IT WORKS

  • Tap one element to pick it, another to mix the two. Tap the pick a second time to lock it, and it survives the mix — which is what makes trying Fire against ten things ten taps instead of twenty.
  • Every attempt is a move, successes and failures alike, and so is a hint. Low scores are the game.
  • Pairs you have already tried grey out, so you never spend a move repeating yourself.
  • Five quests keep score separately, from Unicorns and Rainbows to finding all three hundred elements.
  • The encyclopedia is a journal of every element you have ever found and every recipe you actually performed. Starting a new game wipes the board, never the knowledge.

BUILDING IT

npm install then npm run build writes the 13KB entry; npm run build-director writes the cut. Both are checked by the same headless suite — npm test for the entry, node check.mjs dist/director.html for the cut. The README.md is the long version: what every byte went on, and what was tried and rejected.

Built on the galaxy-raid base — the dark look, the build shape and the CDP test harness all came from there.
